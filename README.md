# Sungsu Jeon — Academic Website

A static, responsive academic website for GitHub Pages.

## Publish

Upload the contents of this folder to the root of Sungsu-Jeon/Sungsu-Jeon.github.io.
In Settings → Pages, choose Deploy from a branch → main → /(root).
No npm, build command, or third-party service is needed.

## Edit

- Content: edit the corresponding HTML file.
- Colors and layout: assets/styles.css.
- Documents and external links: assets/links.js.
- PDFs: files/ directory.
- Images: assets/images/.

The intended public address is https://sungsu-jeon.github.io/.
The homepage is index.html. All links use relative paths so a user site
or a project site can host the same files. Open index.html to preview locally.
